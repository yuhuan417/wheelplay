打开即连接 CarPlay

打开本页即可显示和操作 CarPlay，无需配对。任何能访问本页的浏览器都视为可信，请只在可信局域网中使用。

浏览器麦克风/视频需要 HTTPS

普通局域网 HTTP 页面无法申请麦克风权限，WebCodecs 视频也只在 HTTPS 页面提供。先在 Android 应用的「设置 → 权限与连接帮助 → 浏览器 HTTPS 证书」查看本设备的指纹，逐字核对下方 SHA-256 指纹，再下载证书并在车机浏览器信任。随后打开 HTTPS 页面。
